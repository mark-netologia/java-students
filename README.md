# Java Student Manager

Консольное приложение на Java для управления списком студентов. Проект разработан в рамках учебного задания и включает три уровня сложности: работу с данными и Stream API, реализацию собственной коллекции и разработку универсальных алгоритмов сортировки.

## Функциональность

Программа позволяет:

- Добавлять студентов с указанием имени, среднего балла и номера зачётной книжки.
- Просматривать список всех студентов.
- Загружать данные студентов из CSV-файла.
- Находить студентов со средним баллом от 4.5 и выводить их имена в алфавитном порядке с помощью Stream API.
- Удалять студентов по номеру в списке.
- Сортировать студентов по среднему баллу с выбором алгоритма и направления сортировки.
- Обрабатывать некорректный пользовательский ввод.

## Уровень 1. Работа со студентами и Stream API

Реализовано консольное меню для управления студентами.

Используются:

- Класс `Student` с инкапсулированными полями.
- Чтение данных из CSV-файла.
- Проверка корректности вводимых данных.
- Обработка исключений.
- Stream API: `filter()`, `sorted()`, `map()`, `forEach()`, `anyMatch()`.

Средний балл студента должен находиться в диапазоне от 0 до 5.

## Уровень 2. Собственная коллекция MarkArrayList

Разработана универсальная динамическая коллекция `MarkArrayList<T>` без использования стандартного `ArrayList` для хранения студентов.

Реализованы методы:

- `add(T element)` — добавление элемента с автоматическим увеличением вместимости.
- `get(int index)` — получение элемента по индексу.
- `remove(int index)` — удаление элемента со сдвигом оставшихся.
- `size()` — получение количества элементов.
- `isEmpty()` — проверка коллекции на пустоту.
- `stream()` — получение потока элементов.

Для хранения используется массив `Object[]`, а универсальность обеспечивается с помощью Generics.

## Уровень 3. Алгоритмы сортировки и полиморфизм

Реализованы два собственных алгоритма сортировки:

1. **Bubble Sort** — пузырьковая сортировка.
2. **Selection Sort** — сортировка выбором.

Оба алгоритма реализуют общий интерфейс `SortAlgorithm<T>`:

```java
public interface SortAlgorithm<T> {
    void sort(T[] array, Comparator<? super T> comparator);
}
```

Алгоритмы поддерживают универсальные типы данных благодаря Generics.

Для определения порядка элементов используется `Comparator`, позволяющий сортировать студентов по среднему баллу:

- По возрастанию.
- По убыванию.

Пользователь выбирает алгоритм во время выполнения программы. Полиморфизм позволяет вызывать сортировку через общий интерфейс независимо от выбранной реализации.

Сортировка выполняется над копией списка студентов, поэтому порядок элементов исходной коллекции не изменяется.

## Формат CSV

Файл `students.csv` содержит данные студентов в формате:

```csv
Иван Иванов;4.5;12345
Анна Петрова;4.9;12346
Пётр Сидоров;3.8;12347
```

Поля разделяются символом `;`.

## Запуск программы

Требуется Java 17 или новее.

1. Склонировать или скачать репозиторий.
2. Открыть проект в IntelliJ IDEA.
3. Убедиться, что файл `students.csv` находится в корневой папке проекта.
4. Запустить метод `main()` класса `Main`.

## Меню программы

```text
=======Меню=======
1. Добавить студента
2. Показать студентов
3. Имена лучших студентов по алфавиту (Stream API)

5. Сортировать студентов
0. Выход
```

При выборе сортировки программа дополнительно предлагает выбрать алгоритм и направление.
